 🛍️ Customer Shopping Behavior Analysis

An end-to-end data analytics project that analyzes customer shopping behavior using Python, SQL, and Power BI. The project focuses on data preprocessing, exploratory data analysis (EDA), SQL-based business insights, and interactive dashboard visualization to support data-driven decision-making.


 📌 Project Overview

This project aims to understand customer purchasing patterns by analyzing shopping behavior data. The workflow includes cleaning raw data, performing exploratory analysis, writing SQL queries to answer business questions, and creating an interactive Power BI dashboard for visualization.



 🚀 Tech Stack

- 🐍 Python
- 🐼 Pandas
- 📊 Matplotlib
- 🗄️ SQL
- 📈 Power BI
- 💻 Jupyter Notebook

-> 🛠️ How to Run

->Clone Repository

```bash
git clone https://github.com/Tannu-exe/customer-shopping-analysis.git
```

->Open Project

```bash
cd customer-shopping-analysis
```

-> Install Dependencies

```bash
pip install pandas numpy matplotlib sqlalchemy pyodbc jupyter
```

-> Run Notebook

Open:

```
Customer_Shopping_Behavior_Analysis.ipynb
```

Run all cells in Jupyter Notebook or VS Code.
